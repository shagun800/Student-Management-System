Student Management System

A simple Java-based Student Management System project designed to manage student information through a basic console-based application.

Features

- Add student details
- Display student information
- Simple and easy-to-use Java implementation
- Object-oriented programming concepts

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Git & GitHub

Project Structure

Student-Management-System/
│
├── src/
│   ├── Main.java
│   └── Student.java
│
├── .gitignore
└── README.md

How to Run

1. Clone the repository.
2. Open the project in VS Code or any Java-supported IDE.
3. Compile the Java files.
4. Run "Main.java".

Purpose

This project was created to practice Java programming, classes and objects, and basic student record management.
